# ClientOps Copilot frontend

React, TypeScript, Vite, and Tailwind UI for the ClientOps Copilot single-workspace prototype.

Use the repository-level [`README.md`](../README.md) for setup, configuration, API, security, Docker, and roadmap documentation.

```bash
npm ci
npm run format:check
npm run lint
npm test
npm run build
npm run dev
```

Set `VITE_API_BASE_URL` when the API is not available at `http://127.0.0.1:8000`.
